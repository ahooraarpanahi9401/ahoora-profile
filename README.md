# پروفایل هنری / رزومه (GitHub Pages)

یک صفحهٔ تک‌فایلی (HTML/CSS/JS) برای نمایش پروفایل هنری: نام، بیوگرافی، آهنگ‌ها با پلیر، لینک‌ها و شبکه‌های اجتماعی. کاملاً رایگان روی GitHub Pages قابل میزبانی است.

## ساختار
```
.
├── index.html          # کل سایت (استایل + اسکریپت داخل همین فایل)
├── assets/
│   ├── avatar.jpg      # تصویر پروفایل (اختیاری)
│   ├── track1.mp3      # فایل‌های صوتی
│   ├── track2.mp3
│   └── track3.mp3
└── README.md
```

## ویرایش محتوا
فایل `index.html` را باز کنید و بخش `CONFIG` را در اسکریپت پایین صفحه ویرایش کنید:
- `name`, `tagline`, `bio`
- `stats`, `socials`
- `tracks` (نام، خواننده، مسیر فایل mp3، مدت زمان)
- `about` (پاراگراف‌ها)
- `links` (کارت‌های لینک)

فایل‌های صوتی را در پوشهٔ `assets/` قرار دهید و نامشان را در `tracks[].src` ذکر کنید (مثلاً `"assets/track1.mp3"`).

## انتشار رایگان روی GitHub Pages
1. یک مخزن (Repository) جدید در GitHub بسازید (مثلاً `my-profile`).
2. همهٔ فایل‌ها (index.html + پوشهٔ assets) را آپلود/commit کنید.
3. در GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. بعد از چند ثانیه سایت شما در آدرس زیر در دسترس است:
   `https://<username>.github.io/<repo-name>/`

### نکته
- GitHub Pages فقط فایل‌های استاتیک (HTML/CSS/JS) را سرو می‌کند — دقیقاً همین چیزی که اینجا داریم.
- برای دامنهٔ شخصی (مثلاً `yourname.com`) می‌توانید در تنظیمات Pages یک Custom Domain اضافه کنید.

## همگام‌سازی خودکار پروفایل (profile.json)
- فایل `profile.json` در کنار `index.html` قرار دارد و شامل نام، handle، بیو، آواتار و لینک‌های شماست.
- هنگام بارگذاری صفحه، `index.html` این فایل را می‌خواند و پروفایل را بروزرسانی می‌کند.
- **هر وقت پروفایل تلگرام شما (نام/آواتار/بیو/ایدی) تغییر کرد، فقط `profile.json` را ویرایش کنید** — صفحهٔ شما خودکار بروز می‌شود، نیازی به دست زدن به `index.html` نیست.
- برای همگام‌سازی کاملاً خودکار با تلگرام (بدون ویرایش دستی)، نیاز به یک بک‌اند (مثلاً Cloudflare Worker یا GitHub Action) است که پروفایل تلگرام را بخواند — در صورت تمایل بفرمایید تا بسازم.

## همگام‌سازی لحظه‌ای با تلگرام (GitHub Actions)
- یک **GitHub Action** (`.github/workflows/sync-telegram.yml`) اضافه شد که هر **۱۵ دقیقه** یک‌بار صفحهٔ عمومی پروفایل تلگرام شما (`t.me/heavenlydemongoddd`) را می‌خواند، نام/بیو/عکس را استخراج می‌کند و `profile.json` را بروزرسانی می‌کند.
- همچنین `index.html` هر **۶۰ ثانیه** یک‌بار `profile.json` را می‌خواند — پس وقتی پروفایل تلگرام شما تغییر کند، صفحهٔ شما ظرف **حداکثر ~۱۶ دقیقه** خودکار بروز می‌شود (بدون دست زدن به کد).
- برای فعال شدن Action، مخزن را روی GitHub Push کنید و در تب **Actions** workflow را فعال کنید. اولین اجرای آن را می‌توانید با **Run workflow** (دستی) تست کنید.
- نکته: GitHub Actions روی مخزن **پابلیک** رایگان است. اگر مخزن **پرایوت** باشد، محدودیت دقیقه‌ای دارد (اما برای این کار کم است).

## پیشنهادهای بعدی
- بگویید چه بخش‌هایی اضافه/حذف/تغییر کنم (مثلاً بخش «تور/کنسرت»، «گالری عکس»، «فرم تماس»، «نظرات»، تغییر رنگ/تم، اضافه کردن موج صوتی (waveform) واقعی).
- اگر می‌خواهید متن/اطلاعات واقعی خودتان را جایگزین کنم، بفرستید.
